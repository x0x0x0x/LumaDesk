LumaDesk 3.1.5 — новый дизайн виджетов

НОВОЕ В 3.1.5
Погода обновляется по значку справа вверху; строка провайдера неактивна.
Подсветка нижней надписи календаря выровнена вокруг текста.

НОВОЕ В 3.1.4
Убрано нижнее поле «Новая заметка…». Создание — через плюс в заголовке.
Активная область выровнена по центру вокруг плюса; сам плюс не сдвигался.

НОВОЕ В 3.1.3
Вернул прежнее положение цифр и даты. Подсветка подстраивается под цифры.
Аналоговый циферблат и дата неактивны, секундная стрелка не возвращена.

НОВОЕ В 3.1.2
Убраны настройка секунд и секундная стрелка.
Цифры выровнены по центру рамки, дата не входит в активную область.
Часы обновляются при смене минуты и наведении; ежесекундной перерисовки нет.

НОВОЕ В 3.1.1
Будильники открываются только по цифровому времени.
Аналоговые часы и дата не активны и не подсвечиваются.

НОВОЕ В 3.1
Активные даты, стрелки, карточки, галочки и кнопки подсвечиваются при наведении.
При нажатии оттенок становится заметнее. Пустые области не подсвечиваются.
В часах нажмите плитку города внизу, чтобы выбрать город и часовой пояс.
Есть поиск по популярным городам; можно задать своё название и пояс.
Эти два города сохраняются на этом ПК и не отправляются на сервер.
Сервер обновлять не требуется. Режим синхронизации не изменён.

ЗАПУСК
Закройте старую программу через трей → Выход.
Запустите LumaDesk.exe из этого архива. Заметки и аккаунт сохранятся.
Для расположения как на превью: трей → Выравнивание → Как на примере.
Сначала снимите галочку «Запретить перемещение виджетов», если она включена.

ЗАМЕТКИ
Карточки показывают название и текст. Нажатие открывает полный редактор.
Плюс в заголовке открывает полный редактор новой заметки. «+ Чек-лист» добавляет пункт.
Формат пунктов: - [ ] задача; - [x] выполненная задача.
Галочки переключаются прямо на карточке. Колесо мыши прокручивает список.
Цвета назначаются автоматически и одинаковы на разных компьютерах.

СИНХРОНИЗАЦИЯ
Сервер обновлять не требуется. Все поля заметок совместимы с сервером 2.1.
Трей → Автосинхронизация: снимите галочку для полностью ручного режима.
Автоматическая отправка — через 8 секунд после сохранённых правок;
проверка других ПК — раз в 15 минут. Несохранённый текст не отправляется.
