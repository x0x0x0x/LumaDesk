Проверки синхронизации LumaDesk 2.1

RunChecks.cmd собирает и запускает CloudChecks.cs средствами .NET Framework
в Windows. Программа проверяет объединение событий, удаления, конфликты,
изменения во время запроса, импорт и ограничения HTTPS.
NotesChecks.cs проверяет текст заметок, конфликты, удаления, импорт,
сохранение правок во время синхронизации, лимиты, размеры и перенос настроек.
Тестовые данные вымышленные. Рабочие настройки и аккаунт не читаются.

Для TransportChecks.cs сначала запустите локальный сервер на 127.0.0.1:8765,
затем RunChecks.cmd transport. Проверка создаёт вымышленный аккаунт на этом
локальном сервере и отсылает тестовое событие и многострочную заметку. Пароль не печатается.
Для этой проверки используйте отдельную локальную тестовую базу сервера.

Тесты HTTP API Python: Server/tests/test_api.py, стандартный unittest.

PlacementChecks.cs проверяет восстановление координат всех четырёх виджетов,
отрицательные координаты мониторов, отключение экрана, запись на диск,
резервную копию и независимость позиций от синхронизации.

ThemeChecks.cs проверяет светлую и тёмную отрисовку всех виджетов,
отсутствие кнопок с тремя точками, плавные углы и сохранение темы.
